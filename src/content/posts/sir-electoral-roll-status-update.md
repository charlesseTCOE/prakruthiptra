Karnataka’s SIR draft electoral roll is public. Across the state about **1.08 crore** earlier electors were placed in the ASDDO bucket after enumeration. In Greater Bengaluru, officials have said the draft holds about **56.99 lakh** names, with a large ASDDO list still under notice and hearing.

ASDDO is a flag for verification — not an automatic deletion. Hearings and notice delivery are still running.

## Do this now

1. Search your name / EPIC on [voters.eci.gov.in](https://voters.eci.gov.in) (SIR 2026).
2. If you are missing, file **Form 6** before **23 September**. Camps: **19 and 20 September**.
3. If a detail is wrong, file **Form 8**.
4. If you get a notice, attend the hearing (notices and hearings continue until mid / late October).
